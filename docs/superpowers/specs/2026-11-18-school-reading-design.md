用户已确认需要具体书目，并授权加入 GitHub Data Lab。沿用已获认可的纸色、深绿、衬线标题和静态页面设计，直接实现和发布。

## 内容与交互

- 新增 `/hn/school-reading/`，首页和主导航均可进入。
- 展示已核对的 109 部作品（含系列），书名、原名、作者和完整中文简介始终可读。按九个主类别组织，无排名和提及次数。
- 提供 6–8、9–11、12–14、15–18 岁及年龄未明确的筛选；支持与类别、中英文关键词交叉筛选。筛选写入 URL，刷新和浏览器前进后退可以恢复。
- 80 部作品有分龄依据；29 部完全没有明确年龄。跨组作品可出现在多个年龄组，已知年龄的作品不重复归入年龄未明确组。
- 年龄标签记录讨论中的阅读经历或推荐对象，不作为出版方适龄结论。每本可展开阅读依据和来源，亲子朗读成人作品保留个案说明。
- 提供完整及各年龄、类别的 CSV / JSON、交叉表和 ZIP 下载。网站与下载使用同一份已核对书目文件。

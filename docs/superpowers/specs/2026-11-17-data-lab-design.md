# Data Lab 设计

用户已创建 shcalm/data-lab 并授权整合、发布书籍与电影榜单；延续此前确认的独立 GitHub Pages 项目站方案。

## 页面与内容

- `/data-lab/`：数据作品集首页，两项真实项目卡片、统一的来源及统计时间说明。
- `/data-lab/hn/books/` 与 `/data-lab/hn/movies/`：各 100 项真实排名、原名、作者或上映年、提及次数和中文简介。
- `/data-lab/about/`：统计口径、候选目录限制、快照和发布维护说明。
- 每个项目提供 JSON 与带 UTF-8 BOM 的 CSV 下载。保留原始排名，按当前查询筛选和排序；搜索中文名、原名、作者和简介。主题标签只作为内容导航，不代表新增统计结论。
- 内容在构建时输出为 HTML，关闭 JavaScript 仍能阅读完整榜单；JavaScript 仅增强搜索、排序及简介展开操作。网址 query 参数保存筛选条件，详情使用原生 details。

## 视觉

温暖的纸色背景、近黑文字、深绿强调色，搭配衬线中文标题和清晰的无衬线正文。首页用大标题与留白建立阅读节奏；榜单用简洁分隔线、等宽数字和前三名强调。电脑上采用排名、作品、提及次数三栏；手机上收拢为纵向行，避免横向滚动。无外部字体、封面或第三方脚本依赖。

## 架构与维护

Astro 静态生成；项目 JSON 与页面组件分离，公共目录表统一驱动首页和路由。新榜单按文档添加一份数据和目录配置即可。`base: /data-lab`，所有本地链接通过统一路径函数生成。GitHub Actions 构建、校验并通过 Pages 官方 action 发布。

## 验证

数据校验覆盖排名连续性、重复作品、非空简介、帖子与评论之和、计数降序、两份 100 条与口径元数据。浏览器核验搜索、无结果状态、排序、简介展开、查询网址恢复、下载，以及 375 / 768 / 1440px 布局和键盘可访问性。只有构建、数据和浏览器检查通过后提交并推送；发布后检查线上网址。

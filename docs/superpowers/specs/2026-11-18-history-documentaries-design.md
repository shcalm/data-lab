# 历史与纪录片专题

用户已授权把刚核验的历史书目与纪录片发布到 Data Lab。沿用已认可的纸色、深绿、衬线标题、分类卡片及静态页面；新增首页专题入口和主导航。直接完成实现、验证与发布。

## 内容和阅读体验

- 页面 `/hn/history-documentaries/` 收录 100 项历史书目和 97 部纪录片／纪录系列，其中 64 部属于历史题材子集。
- 三个可链接的视图：历史书目、全部纪录片、历史纪录片。默认展示历史书目；浏览器不运行 JavaScript 时保留两种完整列表及所有下载入口。
- 作品按题材分组，中文名、原名、作者／创作者、年份、形式和两句完整简介直接显示。作品备注和原回复引文在原生 `details` 中展开；引文保留推荐、有保留、提及、比较等语气。
- 搜索中英文名、创作者、内容与类别；可与类别交叉筛选。切换书目／片单视图时重置类别、保留关键词，URL 使用 `view`、`category`、`q`，刷新及浏览器前进后退恢复视图。
- 不展示名次或把证据条数当热度。页面解释专题精选范围、十年窗口与整理日期，提供 18 个讨论来源。
- 下载完整同步已核验的 17 个结果文件和 ZIP，网页从同一公开 JSON 构建，包含两份完整列表和历史纪录片子集的 Markdown、CSV、JSON，逐条证据及校验文件。

## 架构

元数据在 `data/history-documentaries.json`，导出在 `public/downloads/hn-history-documentaries/`。`src/lib/history-documentaries.mjs` 读取并归一化公开数据；独立的纯过滤模块供浏览器脚本和 Node 测试使用。页面复用 `SiteLayout`、书目样式和图标，专题 CSS 仅添加所需视图、引用与下载布局，不新增依赖。首页增加第 4 个项目，关于页补充专题方法和下载。

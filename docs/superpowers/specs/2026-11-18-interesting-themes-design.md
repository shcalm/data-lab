# 值得深挖的主题专题

用户已明确要求把刚整理的主题发布到 Data Lab；既有站点的视觉风格已获认可。本次沿用该设计和发布流程，直接完成研究内容的网页化、验证与发布。

## 阅读设计

新增 `/hn/interesting-themes/`，标题为「换个角度，理解世界」。30 个主题按学习认知、社会制度、自然科学和计算机系统分组，提供全列表与先读精选 12 个的筛选，保留研究中的顺序。页首说明全量发现检索覆盖 2006-10 至 2026-08 的 4,755,791 篇主帖，精选阅读不等于读完全部评论。

每条直接展示主题、一句话洞见、类别及来源数。展开原生 details 后展示中文解释、机制、适用边界、进一步追问、全部原帖及106条原文引文。英文引文另设一层 details，保持长文阅读的轻量。主题标题与分享入口使用去除筛选参数的永久锚点链接，打开即定位并展开相应主题；原帖链接直接去 HN。历史档案与当前 API 中两处作者显示名称差异保留双边信息。

桌面使用有宽裕行距的单栏阅读列表，主题编号置于左侧，正文宽度限制在适合阅读的范围；手机上编号和类别同行。复用纸色、墨绿、衬线标题与全站间距，不新增UI依赖。内容在构建时完整渲染，关闭 JavaScript 仍能阅读30个主题、展开原文并下载。

## 交互与数据

搜索覆盖主题、概述、机制、边界、追问和原帖标题；支持 Unicode 归一化、多关键词交集，与领域、精选筛选组合。URL 使用 `group`、`q`、`view=starters`；未知领域或视图回退为全部。刷新、前进后退还原查询；空结果有明确提示与清空入口。搜索结果更新以 aria-live 告知，按钮有明确按下状态，details 支持键盘操作。

网页从公开下载目录的已核验 `themes.json` 构建，提供与上游字节一致的7个导出文件及ZIP。元数据独立保存在 `data/interesting-themes.json`，纯筛选函数与文件读取模块分开，浏览器仅嵌入筛选需要的轻量字段。首页加第5个专题及示例入口，主导航和关于页同步加入，首页概览改为能够容纳不同时间窗口的介绍。

沿用现有专题结构比套用作品排名页更符合该内容；独立应用会增加重复布局与部署维护，因此采用一个 Astro 专题页加独立数据适配层。

## 验收

保持30／62／106数量、四组7／9／7／7和12个精选入口、全部中文段落及引用不丢失。单元检查确认来源关系、原文引用、复合筛选和未知参数行为。浏览器验收搜索、刷新／前进后退、主题锚点、键盘、无JS、下载字节一致与ZIP，以及320–1440px布局；回归已有页面。发布到main后等待Pages成功，并在线上验收新页面、首页导航与导出文件。

**Goal:** Publish an accessible Chinese reading experience for the verified HN book and movie Top100, with a maintainable home for future datasets.

**Architecture:** Astro renders project data to static HTML. Small shared browser controls filter and sort existing HTML without a client framework. Source snapshots, introductions, metadata and downloadable files remain versioned in the repository.

**Tech Stack:** Astro, TypeScript, plain CSS, Node test runner, Python Playwright, GitHub Pages.

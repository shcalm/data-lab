## 整理方法

1. 沿用前面榜单的十年区间：2016-08-23 08:44:12 至 2026-08-23 08:44:12（UTC）。先检索本地 Hacker News 数据集的帖子标题，并用公开搜索补充候选。
2. 选择专门征集历史书、科学技术史或纪录片的讨论，读取原帖及完整评论树。原文复核日期为 2026-11-18。
3. 识别具体作品，合并同一作品的不同写法；区分书籍、纪录长片、纪录系列与短片。历史小说、仅提作者／频道、不能确定作品身份的内容不收入正式列表。
4. 每部作品保留至少一条可核对的原回复及短引文，标明推荐、提及或其他语气。内容简介由本次整理概括，未标为网友原话。
5. 按题材分类。历史纪录片指以历史事件、人物或社会、文化、科技发展为主要叙事的作品；仅记录当代生活、比赛或当下议题的作品留在其他题材。

这是人工精选的专题书目／片单，未穷尽所有讨论或原帖全部作品。核查回复数仅表示本次保留的证据条数；同一回复可含多部作品，不能解释为票数、读者人数或全站排名。

作品观点不等同于已确认的历史事实；有明确视角、争议或辨认限制的作品在备注中说明。中文书名／片名不确定时保留原名。

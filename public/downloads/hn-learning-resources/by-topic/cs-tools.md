### The Missing Semester of Your CS Education

MIT / Anish Athalye、Jon Gjengset、Jose Javier Gonzalez Ortiz · 公开工具课程 / 练习

集中练习命令行、编辑器、版本控制等开发工具，补齐会写代码却不熟悉工作环境的空缺。适合刚进入Unix开发环境或已有零散工具经验的人。

**适合谁／先修：**基本电脑与编码经验有帮助；已有熟练工具习惯的人可能觉得内容基础。

**推荐理由：**读完材料并看完讲座的学习者报告在Git、Vim与命令行上更熟练；另一条评论清楚提示对经验较深者增益有限。

[资源入口](https://missing.csail.mit.edu/)

**使用备注：**首帖为2020年课程，后续年份有更新；不要将工具课当成完整计算机科学课程。

**推荐 · [wes1350 / 22230116](https://news.ycombinator.com/item?id=22230116)**：完整读看材料后的具体工具熟练度反馈。

> I've read through all the material and watched all the lectures and I can say it has helped me tremendously thus far. I'm still trying to master all the tools they've mentioned but I already feel much more proficient with e.g. version control, vim, using the command line, etc.

**有条件推荐 · [fao_ / 22231332](https://news.ycombinator.com/item?id=22231332)**：已有经验者说明大部分内容自己已会，作为适用程度的保留。

> To be honest, I was kind of disappointed with this, because most of it I already knew! (That's not a criticism of your course c:)

### Learn Git Branching

Learn Git Branching project · 交互式可视化练习

用可视化提交图和闯关操作练习分支、合并与rebase。适合听过Git命令但难以建立分支模型的人。

**适合谁／先修：**有少量Git使用经验会更容易；可作为专项练习，不能替代所有Git概念解释。

**推荐理由：**推荐者认为它能暴露经验开发者的知识空缺；同一讨论也有偶尔使用Git的读者说rebase关卡仍然难懂。

[资源入口](https://learngitbranching.js.org/)

**使用备注：**收录的是一个具体互动教程，不是Git托管平台；推荐与失败体验同时保留。

**有条件推荐 · [guitarbill / 18567670](https://news.ycombinator.com/item?id=18567670)**：保留推荐者对作用范围的明确限定。

> it's not perfect, and isn't going to completely de-mystify git. but it's a great exercise and seems to clear up a thing or two.

**限制／异议 · [russdpale / 18571350](https://news.ycombinator.com/item?id=18571350)**：实际尝试者说明rebase部分对低频使用者未必有效。

> I tried this a while back, and I am so confused by the rebasing part I figured I'd find something else. As someone who knows some git, but only has to used it every once in a while, this website does not help me..

## 怎样找到这些主题与资源

1. 在本地全库的 **4,755,791 条有效主帖**中检索标题，时间范围为 2006-10-09 18:21:51+00 至 2026-08-23 08:43:40+00。使用MOOC、公开课、讲座、自学路线、求推荐等多组关键词，不限于月榜。
2. 标题检索得到 **7,344 个候选帖**，其中 46 个出现在此前的 Ask / Show 月度 Top 10。候选数表示检索命中，不能当作已读帖数或全部相关帖数。
3. 阅读候选讨论，按反复出现的学习问题归纳主题，再挑选有明确正向推荐的具名资源。内容简介和先修建议为中文编辑整理；推荐理由附评论者和原话。课程、教材、目录分开标明形式。
4. 对每条引用核对保存的讨论树，确认原话是去除HTML、解码实体、合并空白后的连续原文；再按评论ID及时间与下载的月度档案核对。共 183 条资源证据、173 个不同引用节点，档案核对结果为 `{"exact": 181, "different": 2}`。非匹配项显式标明只依赖Algolia缓存。
5. 检查资源入口：83 项已记录自动访问结果，其中 63 项请求成功。结果保存在 [link-checks.json](link-checks.json)。HTTP 403、超时等不能单独证明课程失效；HTTP 200也不保证可免费报名、评分或取得证书。历史版本与当前入口的差异写在资源备注里。

这是一份有证据的精选目录，**不按全站提及次数排名，也未穷尽所有课程**。同一个评论推荐多项资源时会分别引用；引用数和来源帖数只表示本次收录的证据，不能用于推断全站受欢迎程度。修过、在学、只看过部分讲座和一般推荐尽量保留原始区别；课程的负面体验也会保留。

# 15–18岁／高中书目

共 23 本书／系列，每行一部作品。

年龄依据包括实际阅读经历和面向该年龄的推荐，详细区别见CSV／JSON中的分龄依据与备注。

|---|---|---|---|

|---|---|---|---|

## 计算机与编程

| 书名 | 作者 | 类别 | 内容简介 |
|---|---|---|---|
| 编码：隐匿在计算机软硬件背后的语言 | Charles Petzold | 计算机与编程 | 从通信、开关和逻辑电路出发，逐步解释计算机如何工作。它把硬件与软件之间的抽象层连接起来。 |
| How Computers Really Work | Matthew Justice | 计算机与编程 | 从硬件和数字表示等基础介绍计算机内部原理。结合练习连接电路、软件和系统行为。 |
| 程序设计方法 | Matthias Felleisen、Robert Bruce Findler、Matthew Flatt、Shriram Krishnamurthi | 计算机与编程 | 通过数据分析和系统化设计步骤教授程序设计。重点是如何从问题描述推导出结构清楚的程序。 |
| 编程珠玑 | Jon Bentley | 计算机与编程 | 通过具体问题讨论算法、数据结构和程序优化。着重展示如何分析问题并找到简洁有效的解法。 |
| The Computational Beauty of Nature | Gary William Flake | 计算机与编程 | 介绍分形、混沌、复杂系统和适应等计算主题。通过模型说明简单规则如何形成复杂现象。 |
| The Computer Always Wins | Elliot Lichtman | 计算机与编程 | 通过游戏和谜题切入计算机问题。读者可以从具体策略理解算法和解决问题的方式。 |
| 布谷鸟的蛋 | Clifford Stoll | 计算机与编程 | 系统管理员从微小的账目异常追查入侵者。真实调查经历呈现早期网络安全、耐心取证和跨机构合作。 |
| 计算机系统要素 | Noam Nisan、Shimon Schocken | 计算机与编程 | 从逻辑门逐步构建处理器、汇编器、编译器和操作系统。配套项目让读者理解一台计算机的完整组成。 |
| The Little Schemer | Daniel P. Friedman、Matthias Felleisen | 计算机与编程 | 以连续问答和短程序讲解递归及函数式思考。读者通过小例子逐步建立对程序结构的直觉。 |
| 新黑客词典 | Eric S. Raymond | 计算机与编程 | 收集黑客社群的术语、笑话和技术文化。它也是了解早期计算机社区语言习惯的窗口。 |
